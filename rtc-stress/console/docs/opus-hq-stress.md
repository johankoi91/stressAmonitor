前一轮同为 A300/B350/C350、标准音频、400 个独立发布连接，但输入为双声道 PCM，由 SDK 默认档位实时编码，实际输出为约 64 kbps 的 Opus 单声道。本轮使用已离线生成的 128 kbps 单声道语音，完整保留 UID、发布和订阅数量，运行期间直接发送编码包。因此两轮是发送路径与资源对照，音频净负载约翻倍，并非完全相同的编码/网络工作量。

本轮消除了逐 UID 实时编码的任务，剩余开销包括 SDK 协议、网络收发、加密、调度、内存操作与接收统计。压测数据包含独立的 encodedSent、audioFramesSent、audioSentMicros 和编码包匹配计数；页面按输入类型标注发送量。
