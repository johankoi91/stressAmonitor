# 自适应监控粒度

- 最近 15 分钟、1 小时：每点为 5 秒内有效采样的均值，保留最近 1 小时，最多 720 点/节点。
- 最近 3、6、12 小时：每点为 5 分钟均值，保留 12 小时。
- 实时卡片继续使用最近原始采样。时间轴缺失区间留空。
- 短时图表显示秒，方向键每次移动 5 秒；长时图表每次移动 5 分钟。切换范围会恢复刷新。
- API 使用 /api/telemetry?interval=5 或 interval=300；未指定时默认 300，兼容旧客户端。两套数据独立缓存和增量获取。
- 新增 5 秒历史从版本更新后开始累计，不对已有 5 分钟记录插值。原长时历史继续保留。
- 新数据持久化保存在原 telemetry.json；5 秒历史每 30 秒检查点，正常关闭时完整保存，异常断电可能丢失最近一个检查点后的采样。

- 移动鼠标时，四张图共用同一采样时刻的游标；当前图浮层显示日期、时间、均值粒度及各节点数值，缺失点显示“无采样”。键盘方向键、Home/End 同样可查看，Escape 关闭。
